## Projects

### 英単語暗記アプリ / Vocabulary Spaced-Repetition Web App
忘却曲線に基づいて復習のタイミングを管理する英単語学習アプリ。友人が日常的に利用中。  
A web app that schedules vocabulary reviews based on the forgetting curve. Used daily by friends.

- 1→3→7→14日の間隔反復。本人のミス率から1日の出題量を調整
- Web Push による復習リマインダー（普段の学習時刻の15分前など）
- CSV からの単語帳取り込み、Web Speech による発音
- Tech: Python / PostgreSQL (Supabase, RLS) / Google OAuth / Render / Web Push
- 128 automated tests on a local PostgreSQL environment

※ ソースコードは非公開です / Source code is private.
